# Sample Project — Contoso Contact Center Migration

This is a sample project structure to show how D365 Architect OS organizes project data.

The main project file lives at `../contoso-contact-center.json` and contains:
- Project metadata
- Context (client, modules, current/desired state)
- Decisions
- Assumptions
- RAID log
- Artifact references

Generated artifacts are saved to this directory as markdown files.
